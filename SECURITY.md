# Security Policy

## Supported versions

The latest version on the default branch is supported while Retr-0 is in active development.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the maintainer privately with a description, reproduction steps, affected files, and potential impact. Do not include personal data or real browsing content in a report.

Retr-0 is designed not to execute arbitrary page JavaScript, intercept unrelated network requests, collect browsing history, or send website contents to a server. Reports that identify a violation of these guarantees are especially important.
